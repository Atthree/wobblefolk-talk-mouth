# Wobblefolk Talk Mouth

Voice-driven mouths for any character in Unity 6: jaws, blend shapes, beaks, sprites, physical ragdoll jaws and
split heads, driven by AudioSources, the microphone, voice chat SDKs, typed dialogue or baked clips.

Quick start: select a character and open *Wobblefolk > Setup Talk Mouth*, or import a sample from the Package Manager.

Full documentation (English and Turkish): https://github.com/Atthree/wobblefolk-talk-mouth#readme
