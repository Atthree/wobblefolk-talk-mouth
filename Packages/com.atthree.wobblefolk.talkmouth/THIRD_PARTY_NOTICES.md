# Third-party notices

This package contains no third-party code, models, audio or other assets. All code was written from scratch, and the
sample voices are synthesised by the package itself.

The following open-source projects were studied for ideas only. No code, assets or text were copied from them.

| Project | License | Studied for |
|---|---|---|
| [uLipSync](https://github.com/hecomi/uLipSync) | MIT | Analysing the voice spectrum per frame to pick mouth shapes; baking clips ahead of time |
| [Rhubarb Lip Sync](https://github.com/DanielSWolf/rhubarb-lip-sync) | MIT | A small set of coarse mouth shapes that read well on stylised characters |
| [huailiang/LipSync](https://github.com/huailiang/LipSync) | MIT | Formant-based vowel recognition from spectrum energy |
| LipSyncLite | MIT | Keeping the analysis cheap enough for many characters |
| [curefate/animalese-unity](https://github.com/curefate/animalese-unity) | MIT | Babble voices made of short blips per letter for typed dialogue |

Proprietary lip sync SDKs (for example Oculus LipSync) were not used.
